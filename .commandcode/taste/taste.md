# Taste

- For small web pages/sites, strongly prefers plain HTML + CSS + vanilla JS: no frameworks, no build step, no external libraries. Confidence: 0.55
- Wants code written to be beginner-editable — clearly sectioned and thoroughly commented (e.g. "EDIT ME" markers for links/text/theming). Confidence: 0.5
- Treats accessibility as a first-class requirement: WCAG AA contrast, semantic HTML, visible keyboard focus states, aria-labels, `prefers-reduced-motion`, and optional `prefers-color-scheme` dark mode. Confidence: 0.5
- Performance-conscious for front-end work: prefers inline SVG over icon libraries, preconnect + `font-display: swap` for fonts, no layout shift, and a tight page-weight budget. Confidence: 0.45
